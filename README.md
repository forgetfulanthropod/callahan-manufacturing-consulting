# Callahan Manufacturing Consulting

Public website for **Callahan Manufacturing Consulting** — EV manufacturing advisory for OEM and Tier-1 programs.

The live site covers:

- Capabilities across battery, e-drive, body/paint, launch, quality, supply chain, cost, and digital
- An index of **100 plant problems** we staff, searchable and filterable
- Eight case studies with photography (client names withheld until you disclose them)
- Practice, principals, and a contact form

## Fill it in

See [CONTENT.md](CONTENT.md). Copy, case studies, the problem index, and contact details are all data files. Drop replacement photography into `public/images/`.

## Run locally

```bash
npm install
npm run dev
```

```bash
npm run build
npm run typecheck
```

## Stack

React 19, TanStack Start, Tailwind v4, TypeScript. Deployable to Vercel.
